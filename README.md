# Let's Grow with LG전자 · 수업 만족도 조사 — 세팅 가이드

K-뉴딜 아카데미 "Let's Grow with LG전자" 실무교육의 수업 만족도 조사 시스템입니다.
정적 웹페이지(GitHub Pages) + Firebase(Firestore) 실시간 저장 + 엑셀(VBA) 취합 구조로 동작합니다.

## 구성 파일

| 파일 | 용도 |
|------|------|
| `index.html` | 웹앱 화면(마크업·스타일) |
| `app.js` | 웹앱 로직 + **Firebase 설정값**(여기서 firebaseConfig 수정) |
| `ImportSurveyData.bas` | 응답 데이터를 엑셀로 자동 취합하는 VBA 모듈 |
| `수업데이터_더미.xlsx` | 트랙·지역·기수·일자별 수업 데이터 예시 |
| `학생_더미.xlsx` | 학생(트랙·지역·기수) 등록 예시 |
| `SETUP_GUIDE.md` | 본 문서 |

> `index.html` 과 `app.js` 는 **같은 폴더에 함께** 두어야 합니다(둘 다 git 에 올려야 함).

## 동작 방식 한눈에 보기

```
학생/관리자 브라우저 ─(index.html)→ Firebase Firestore(실시간 저장)
                                          │
관리자: "전체 응답 CSV" 내려받기 ←────────┘
                │
                ▼
        Excel(.xlsm) + ImportSurveyData.bas  ← CSV 취합 또는 Firebase 직접 조회
```

> **왜 Firebase 인가?** GitHub Pages 는 정적 호스팅이라 서버에서 엑셀 파일에 직접 쓸 수 없습니다.
> 그래서 응답은 Firebase 에 실시간 저장하고, 엑셀은 VBA 로 그 데이터를 취합합니다.
> Firebase 설정 전에는 자동으로 **로컬 저장 모드**로 동작하므로 바로 테스트할 수 있습니다.

## 로그인 규칙

- **관리자**: 학번 입력란에 `000000` 입력 → 관리자 모드
- **학생**: 관리자가 **등록한 학번만** 로그인 가능 (미등록 학번은 거부)

---

## 1단계 · 바로 테스트 (설정 없이)

1. `index.html` 을 더블클릭해 브라우저로 엽니다.
2. `000000` 으로 로그인 → **① 수업 데이터** 탭에서 `수업데이터_더미.xlsx`(또는 템플릿) 업로드. (엑셀 열: 트랙·날짜·제목·내용)
3. **학생 관리** 탭에서 학생을 등록(또는 `학생_더미.xlsx` 업로드). **트랙·지역·기수**를 정확히 지정합니다.
4. **② 만족도 조사 생성** 탭에서 회차 입력 → 구분(일간/주간) 선택 → 날짜(일간) 또는 기간(주간) 지정 → **조사 생성**. 미리보기에 대상 수업 건수가 표시됩니다.
5. 로그아웃 → 등록한 학번으로 로그인 → 내 트랙의 열린 조사에 응답 제출.
6. 다시 관리자로 로그인 → **응답 현황** 에서 결과 확인.

이 단계에서는 데이터가 그 브라우저에만 저장됩니다(로컬 모드). 여러 기기·실서비스는 아래 Firebase 설정이 필요합니다.

---

## 2단계 · Firebase 연결 (실시간 저장)

1. https://console.firebase.google.com 에서 **프로젝트 만들기**.
2. 좌측 **빌드 > Firestore Database > 데이터베이스 만들기** → "테스트 모드"로 시작.
3. 프로젝트 개요 옆 **⚙ > 프로젝트 설정 > 내 앱 > 웹(</>)** 추가 → `firebaseConfig` 값 복사.
4. **`app.js`** 상단의 아래 부분을 복사한 값으로 교체:

```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

5. 저장 후 브라우저에서 열면 상단에 "☁ 클라우드(Firebase) 연동됨"이 표시됩니다.

### Firestore 보안 규칙 (중요)

테스트 모드는 30일 후 만료됩니다. 운영 시 **규칙(Rules)** 탭에서 아래처럼 설정하세요.
가장 간단한 설정(누구나 읽기/쓰기 — 사내/교육용 임시):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

> 개인정보(학번·이름)가 포함되므로, 가능하면 Firebase Authentication 을 추가하거나
> 접근 URL 을 비공개로 관리하세요. VBA 의 Firebase 직접 조회를 쓰려면 `read` 는 열려 있어야 합니다.

생성되는 컬렉션: `students`(학생), `curriculum`(수업 데이터), `surveys`(만족도 조사), `responses`(응답).

## 3단계 · GitHub 등록 & 게시 (GitHub Pages)

1. GitHub 에서 새 저장소 생성 (예: `letsgrow-survey`).
2. `index.html` 과 `app.js` 를 저장소 최상단에 함께 업로드(웹 UI 드래그 또는 아래 명령).

```bash
git init
git add index.html app.js
git commit -m "만족도 조사 웹앱"
git branch -M main
git remote add origin https://github.com/<사용자명>/letsgrow-survey.git
git push -u origin main
```

3. 저장소 **Settings > Pages** → Source: `main` / `/ (root)` → Save.
4. 잠시 후 `https://<사용자명>.github.io/letsgrow-survey/` 주소로 공개됩니다.
5. 이 주소를 학생들에게 배포하면 됩니다.

> `firebaseConfig` 는 클라이언트에 노출되는 값이라 GitHub 에 올려도 괜찮습니다(Firebase 설계상 정상).
> 다만 보안 규칙으로 접근을 통제하세요.

## 4단계 · 엑셀(VBA) 자동 연동

### 방법 A — CSV 취합 (Firebase 없이도 가능)

1. 웹앱 관리자 **응답 현황 > "전체 응답 CSV (VBA 연동용)"** 클릭 → `survey_responses.csv` 저장.
2. 엑셀 새 통합문서 → `Alt`+`F11` → **파일 > 파일 가져오기** → `ImportSurveyData.bas` 선택.
3. 통합문서를 **`.xlsm`(매크로 사용 통합 문서)** 으로 저장.
4. `Alt`+`F8` → `ImportFromCSV` 실행 → 방금 받은 CSV 선택 → 시트에 자동 취합·표 서식 적용.

### 방법 B — Firebase 직접 조회 (엑셀에서 버튼 한 번)

1. `ImportSurveyData.bas` 상단 `FB_PROJECT_ID` 를 본인 프로젝트 ID 로 수정.
2. Firestore 규칙에서 `read` 가 허용돼 있어야 함(위 참고).
3. `Alt`+`F8` → `RefreshFromFirebase` 실행 → 최신 응답을 바로 시트로 가져옴.
4. (선택) 통합문서 열 때 자동 새로고침: `ThisWorkbook` 모듈에
   ```vba
   Private Sub Workbook_Open()
       ImportSurveyData.AutoRefreshOnOpen
   End Sub
   ```

## 만족도 조사 문항 (표준 템플릿, 5점 척도)

1. 수업이 전반적으로 만족스러웠다
2. 강사의 강의 전달력이 좋았다
3. 수업 난이도가 적절했다
4. 수업 내용을 잘 이해할 수 있었다
5. 실무에 도움이 될 것 같다
6. 자유 서술 (개선점·좋았던 점)

위 5개는 **기본 문항**입니다. 실제 문항은 **조사 생성/수정 화면에서 조사별로 편집**할 수 있으며, 비워두면 이 기본값이 쓰입니다. 모든 조사에 공통으로 적용할 기본값 자체를 바꾸려면 `app.js` 의 `QUESTIONS` 배열을 수정하세요.

> 응답 내보내기: **CSV(방법 A)** 는 각 조사의 실제 문항 이름을 열 제목으로 보존합니다. **Firebase 직접조회(방법 B)** 는 조사마다 문항이 달라 `문항1~8` 로 표기됩니다.

## 동작 개념 (중요)

- **① 수업 데이터(커리큘럼)** 와 **② 만족도 조사** 는 분리된 탭입니다. 엑셀 업로드는 회차를 만들지 않고 **수업 데이터를 파이어베이스에 저장(업데이트)** 만 합니다.
- **회차 자동 부여**: 업로드된 수업은 **날짜 빠른 순으로 1회, 2회…** 회차가 자동 부여됩니다(수업 데이터 목록에 표시). 조사 생성 시 회차는 선택한 날짜에 맞춰 자동으로 채워집니다.
- **트랙·지역·기수로 분리**: 매칭 키는 **트랙 + 지역 + 기수 + 날짜**입니다. 같은 AX라도 **기수(강사)가 다르면 별도 조사**로 관리됩니다. 학생 등록·수업 데이터 모두 지역·기수를 입력합니다.
- **조사 생성**: ② 탭에서 **트랙·지역·기수**와 **날짜(일간)/기간(주간)** 을 지정해 조사를 만듭니다. 트랙/지역/기수를 **전체**로 두면 그 날짜에 존재하는 **조합별로 각각** 생성됩니다(예: AX 부산 1기·2기 → 조사 2개 자동 분리).
- **기본 상태 = 오프**: 새로 만든 조사는 **오프(미게시)** 상태이며, 목록에서 **온**을 눌러야 학생에게 게시됩니다.
- **문항 편집**: 조사 생성/수정 시 **만족도 문항을 직접 수정·추가·삭제**할 수 있습니다(조사마다 문항이 다를 수 있음). 비워두면 기본 5개 문항이 사용됩니다. 자유서술은 항상 포함됩니다.
- **수정**: 생성된 조사 목록의 **수정** 버튼으로 회차·구분·트랙·지역·기수·날짜/기간·제목·문항을 편집할 수 있습니다.
- **학생 노출**: 학생은 자신의 **트랙·지역·기수**가 모두 일치하는 **온 상태** 조사만 봅니다. 조사 선택 목록에 `✓ 응답완료` / `· 미응답` 이 표시됩니다.

## 운영 팁

- **회차 관리**: 관리자 **회차·조사 관리** 탭에서 회차 번호를 넣어 조사를 생성합니다. 목록의 **온/오프 버튼**으로 각 회차 조사를 여닫을 수 있습니다.
- **온/오프 동작**: **온(●)** 인 조사만 학생 화면에 표시·응답 가능하고, **오프(○)** 로 바꾸면 학생 목록에서 사라지고 응답이 막힙니다(마감). 언제든 다시 온으로 열 수 있습니다.
- **날짜**: 조사 생성 시 날짜는 당일로 자동 설정되며 달력에서 수정 가능합니다.
- **구분**: 일간/주간을 선택해 등록하고, 목록·응답에서 배지로 구분됩니다.
- **중복 응답 방지**: 학생이 같은 회차에 이미 응답하면 재응답이 막힙니다.
- **정기 취합**: 주 1회 CSV 내려받아 엑셀에 취합하거나, 방법 B로 실시간 조회하세요.

문항·트랙·디자인 조정이 필요하면 `app.js`(로직·문항)와 `index.html`(화면)을 수정 후 다시 push 하면 됩니다. 만족도 문항은 `app.js` 의 `QUESTIONS` 배열에서 바꿀 수 있습니다.
